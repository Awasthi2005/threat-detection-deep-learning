In-Depth Theoretical & Architectural Analysis

RNN

Vanilla Elman RNN

$$\mathbf{h}_t = \tanh(\mathbf{W}_{ih} \mathbf{x}_t + \mathbf{b}_{ih} + \mathbf{W}_{hh} \mathbf{h}_{t-1} + \mathbf{b}_{hh})$$
  • Gradient Flow: $\frac{\partial \mathbf{h}_T}{\partial \mathbf{h}_t} = \prod_{k=t+1}^T \mathbf{W}_{hh}^T \text{diag}(1 - \tanh^2(\mathbf{a}_k))$.
  • Vanishing Gradient: If largest eigenvalue $\lambda_{\max}(\mathbf{W}_{hh}) < 1$ or $\tanh'$ saturates, gradients decay exponentially as $\gamma^{T-t} \to 0$.
  • Exploding Gradient: If $\lambda_{\max}(\mathbf{W}_{hh}) > 1$, gradients explode exponentially $\to \infty$, causing NaN/Inf updates without clipping.
  • Pros / Cons: Minimal parameters & fast compute, but incapable of capturing dependencies beyond ~15-20 timesteps.
BiRNN

Bidirectional RNN (BiRNN)

$$\mathbf{h}_t = [\vec{\mathbf{h}}_t \,;\, \overleftarrow{\mathbf{h}}_t], \quad \vec{\mathbf{h}}_t = f(\mathbf{x}_t, \vec{\mathbf{h}}_{t-1}), \quad \overleftarrow{\mathbf{h}}_t = f(\mathbf{x}_t, \overleftarrow{\mathbf{h}}_{t+1})$$
  • Dual Recurrence: Processes sequence in forward ($1 \to T$) and reverse ($T \to 1$) directions simultaneously.
  • Contextual Representation: Every timestep $t$ receives complete past and future context.
  • Gradient Behavior: Doubles gradient paths, but individual directional paths still suffer from standard RNN vanishing gradient limits unless paired with LSTM/GRU gating.
  • Use Cases: Ideal for non-causal sequence tasks (NLP text classification, POS tagging, DNA sequence parsing).
LSTM

Long Short-Term Memory (LSTM)

$$\begin{aligned} \mathbf{f}_t &= \sigma(\mathbf{W}_f [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_f) \quad \text{(Forget Gate)} \\ \mathbf{i}_t &= \sigma(\mathbf{W}_i [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_i) \quad \text{(Input Gate)} \\ \mathbf{c}_t &= \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tanh(\mathbf{W}_c [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_c) \quad \text{(Cell State)} \\ \mathbf{o}_t &= \sigma(\mathbf{W}_o [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_o), \quad \mathbf{h}_t = \mathbf{o}_t \odot \tanh(\mathbf{c}_t) \end{aligned}$$
  • Constant Error Carousel: The cell state update $\mathbf{c}_t = \mathbf{f}_t \odot \mathbf{c}_{t-1} + \dots$ provides an additive gradient highway where $\frac{\partial \mathbf{c}_t}{\partial \mathbf{c}_{t-1}} = \mathbf{f}_t$.
  • Vanishing Gradient Solution: When forget gate $\mathbf{f}_t \approx 1$, gradients propagate unimpeded across 100+ timesteps without exponential decay.
  • Complexity: 4 weight matrices ($W_f, W_i, W_c, W_o$), resulting in ~4x parameters over Vanilla RNN.
GRU

Gated Recurrent Unit (GRU)

$$\begin{aligned} \mathbf{z}_t &= \sigma(\mathbf{W}_z [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_z) \quad \text{(Update Gate)} \\ \mathbf{r}_t &= \sigma(\mathbf{W}_r [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_r) \quad \text{(Reset Gate)} \\ \tilde{\mathbf{h}}_t &= \tanh(\mathbf{W} [\mathbf{r}_t \odot \mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}) \\ \mathbf{h}_t &= (1 - \mathbf{z}_t) \odot \mathbf{h}_{t-1} + \mathbf{z}_t \odot \tilde{\mathbf{h}}_t \end{aligned}$$
  • Streamlined Architecture: Combines cell and hidden states into a single state $\mathbf{h}_t$ using 2 gates (Reset $r_t$, Update $z_t$).
  • Gradient Flow: Update gate $z_t$ acts as adaptive linear interpolation. When $z_t \approx 0$, state is passed unchanged ($\mathbf{h}_t \approx \mathbf{h}_{t-1}$), preserving gradient flow.
  • Param Efficiency: ~25% fewer parameters than LSTM, training faster while matching accuracy on most sequence benchmarks.
